В коде задействованы стандартные библиотеки Python: sys, os, platform и json. С помощью модуля sys скрипт определяет платформу операционной системы, модуль os позволяет получить текущую рабочую директорию и количество логических процессоров, библиотека platform даёт развёрнутые сведения об ОС, аппаратной архитектуре и версии самого интерпретатора Python, а модуль json отвечает за сохранение собранных данных в структурированном JSON‑формате. При запуске программа получает характеристики ОС: идентификатор платформы, название и релиз ОС, сведения об архитектуре и процессоре, версию Python, число доступных процессоров и путь к текущей рабочей папке, после чего упаковывает эти данные в словарь и записывает в файл os_info_report.json.
